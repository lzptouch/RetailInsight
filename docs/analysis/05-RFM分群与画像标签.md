# RFM 分群与画像标签

> 对应域：D3（分群与画像）。关键数字见 `README.md` 关键数字表。

## 〇、摘要

D3 是整条流水线的「业务语义层」：把交易数据翻译成运营听得懂的语言——8 类 RFM 客群、4 级会员漏斗、38 个画像标签、4 档 CLV 分层。所有口径的**唯一实现处**是 `retailinsight/features/`，notebook 与看板只调用不重算。

## 一、RFM 口径（`features/rfm.py`，指标单一真相源）

| 口径 | 定义 |
|---|---|
| 基准日 | 数据最大交易日期 **+ 1 天**（描述性分析，覆盖全量窗口） |
| R | 基准日 − 最近一次消费日期（天） |
| F | 观察窗内消费次数，**同日多单合并计 1 次** |
| M | 观察窗内**净消费额**（实付 − 退货）；退货单参与净额但**不参与 F** |
| 打分 | R/F/M 各自五分位打分（1~5），≥3 记「高」 |
| 分群 | 2×2×2 规则映射 8 类客群（`SEGMENT_RULES`） |

统计范围：仅 `member_type=="会员"` 且非 `is_logic_error` 的交易。

### 8 类客群映射（`rfm.py: SEGMENT_RULES`）

| (R高,F高,M高) | 客群 |
|---|---|
| (1,1,1) | 重要价值客户 |
| (1,0,1) | 重要发展客户 |
| (0,1,1) | 重要保持客户 |
| (0,0,1) | 重要挽留客户 |
| (1,1,0) | 一般价值客户 |
| (1,0,0) | 潜力客户 |
| (0,1,0) | 一般保持客户 |
| (0,0,0) | 流失风险客户 |

### 分群结果（实测，见关键数字表）

- 价值高度集中：重要价值客户 18.3% 人数贡献 42.5% GMV；两个头部客群合计 36.6% 人贡献 77.8% GMV。
- 风险侧：流失风险客户 37.8%，平均 305 天未消费，仅贡献 9.8% GMV。
- 人均净消费：重要价值客户 2,784.4 元。

## 二、会员漏斗

注册 → 首购 **99.0%** → 复购 **71.5%** → 高频 **39.2%**。

- 最大可运营池 = 「有复购未达高频」的 **15,494 人**——决策报告 S 系建议的主要对象。
- 漏斗的价值不在比率本身，而在**定位干预层级**：每一级掉落对应一类运营动作（首购礼 → 复购券 → 频次权益）。

## 三、画像标签（`features/tags.py` + `p1_tags.py`）

### P0 标签 20 个（4 组 × 5）

| 组 | 示例 |
|---|---|
| 基础属性 5 | 性别、年龄段、城市档位、注册门店、会员龄 |
| 消费能力 5 | 净消费额、客单价、件单价、购买件数、折扣敏感度 |
| 行为偏好 5 | 偏好品类、偏好品牌、时段带（`HOUR_BANDS` 4 段）、周末占比、品类熵 |
| 生命周期 5 | R/F/M、距上次消费天数、客群 |

### P1 扩展标签 18 个（`features/p1_tags.py`）

在 P0 基础上加深行为序列与偏好结构（如复购间隔、品类迁移、价格带偏好等），供画像卡片与看板下钻展示。

### 派生行为指标（`features/behavior.py`）

- `discount_sensitivity`：折扣敏感度（折扣单占比口径）。
- `weekend_ratio`：周末消费占比。
- 品类熵：`_entropy`（tags.py）衡量购买品类的分散度，区分「专一型 / 逛店型」。

## 四、画像宽表（`mart_member_profile.parquet`）

`cli.py: stage_profile` 合并 6 个输入（members / txn / items / products / rfm / churn）产出：

- 列 = P0(20) + P1(18) + CLV(4 列：`clv`、`clv_method`、`clv_tier` 等)；
- 含 `churn_prob`（来自 `mart_churn_score`）与 `churn_covered` 覆盖率打印（`cli.py:113-115`）；
- CLV 双口径：主 BG/NBD（`clv_method` 标识），简化法留作对照列与降级路径。

## 五、CLV 分层

- 4 档分层，主口径 = **未来 12 个月期望毛利**（BG/NBD × Gamma-Gamma × 毛利率 30%）。
- 毛利率是**假设值**（行业常见 25%~35%），报告与画像卡片均标注。
- 模型细节与回测见 `06-建模链路.md` §四；本篇只管「分层结果如何进入画像」。

## 六、口径纪律

1. `features/` 是唯一实现处；看板、notebook、报告**禁止重算**。
2. RFM 口径变更必须同步：SQL 版（`etl/warehouse.py` 自证实现）+ `tests/features/test_rfm.py`。
3. 触达建议不进画像表——建议由 `reports/profile_cards.py` 的规则表按客群生成，画像与建议解耦。

## 七、边界与已知缺口

1. RFM 五分位打分对极端值敏感（头部会员 M 极高会拉高分位边界）——已用聚类法交叉验证（见 `segment_compare`）。
2. 标签以描述性统计为主，无标签的稳定性监控（生产化需补 PSI 类监控）。
3. 漏斗「高频」阈值是业务定义而非数据驱动，换业务需重新定义。

## 维护触发

改 RFM 口径 → `rfm.py` + `warehouse.py` SQL + 测试三处同步；新增标签 → `tags.py`/`p1_tags.py` + 画像卡片规则表评估是否受影响。
