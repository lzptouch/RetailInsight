## 〇、一句话定位

RetailInsight 是一条**从合成数据生成到含量化测算的决策建议**的完整数据分析流水线：生成 → 清洗 → RFM 分群 → 聚类 → 关联规则 → 流失预测 → CLV → 画像 → 报表/看板，全程 14 个 stage 一键串联（`make all`，约 2.5 分钟），所有结论数字由代码回填、可复现。

> **合规口径**：全部数据由 `scripts/generate_synthetic.py` 算法生成，**不含任何真实个人信息**；8 类先验人群与 4 组购物篮关联为**埋点**，用于验证聚类与规则挖掘的有效性。

**度量能力已具备**：

| 能力 | 状态 | 证据 |
|---|---|---|
| 聚类有效性可验证 | ✅ | 先验人群埋点 + ARI 择优 + 神谕上界检验；K-Means 轮廓 **0.4165**（验收线 0.35） |
| 规则挖掘可验证 | ✅ | 4 组预埋组合**全部回收**，最强 洗发水→护发素 lift **8.30** |
| 流失模型时间外验证 | ✅ | 三向时间切分；RF AUC **0.830** vs LR 0.7995（**+0.0305**）；Top20% 捕获 **46.77%** |
| CLV 时间外回测 | ✅ | 91 天回测：金额 MAE **229.3 vs 270.8**（降 15.3%），偏差 **−1.4 vs +74.4** 元 |
| 口径一致性自证 | ✅ | DuckDB SQL 版 RFM 与 pandas 版 **35,650 行零差异** |

仍未证明的：**真实数据上的结论外推**（全部结论基于合成数据，门店级品类差异度 0.0502 落在真实区间下沿，量级偏保守）——登记在 `01-能力全景.md` §六与各篇「边界与已知缺口」。

### 1.2 数据规模

| 维度 | 数值 |
|---|---:|
| 会员 | **36,000**（注册口径），其中 **17,937** 人有重复购买 |
| 门店 / SKU | **15** 家 / **5,000** |
| 交易 / 明细 | 315,139 → 清洗后 **313,571** 笔 / **2,174,049** 行 |
| 有效分析窗口 | 2020-01 ~ 2022-07，共 **31** 个月、**308,956** 笔有效交易 |
| 品类 | **60** 个（含 4 组关联埋点所需品类） |
| 画像标签 | P0 **20** 个 + P1 **18** 个 + CLV **4** 列 |

### 1.3 核心结果

| 主题 | 数值 |
|---|---|
| RFM 8 类客群 | 重要价值客户 6,531 人（18.3%）贡献 **42.5% GMV**；36.6% 会员贡献 77.8% GMV |
| 风险侧 | 流失风险客户 13,485 人（37.8%），平均 **305 天**未消费；模型标记高危 **5,014** 人 |
| 会员漏斗 | 注册→首购 **99.0%**，首购→复购 **71.5%**，复购→高频 **39.2%**；最大可运营池 **15,494** 人 |
| K-Means | 4 簇，轮廓系数 **0.4165**（验收线 0.35） |
| 流失模型 | RandomForest AUC **0.830**；KS **0.4936**；Top20% lift **2.34**（理论上限 2.72 的 86%） |
| 关联规则 | 品类级 **177** 条（lift>1.5）/ SKU 级 **48** 条 / 分门店 **1,092** 条 |
| 品类集中度 | Top5 品类合计 **63.1%** GMV；高峰 10/9/11 点；周末订单占比 29.7% |

### 1.4 工程基线

| 维度 | 数值 | 依据 |
|---|---:|---|
| 分块流式生成 | 20 万会员 / 1,200 万明细 **5.2s**，峰值内存 ≈1.0GB，落盘 108MB | `reports/性能报告.md` |
| 明细分区 | 按月分区（hive 风格），读最近 3 个月仅占全量 **20.2%** | `retailinsight/io/loader.py` |
| SQL 自证 | DuckDB 版 RFM 与 pandas 版 35,650 行**零差异** | `retailinsight/etl/warehouse.py` |
| 看板首屏 | 实测 **0.51s**（验收线 < 3s） | `dashboard/app.py` 首屏计时 |
| 全链路耗时 | `make all`（14 stage，scale 0.3）约 **2.5 分钟** | 根 `README.md` |
