# 模型选型与实验基线（专题）

> 对应 Kquery 的「检索策略推荐表」专题。本篇把三个「为什么选它」的实验证据集中登记，供答辩深挖。关键数字见 `README.md` 关键数字表。

## 〇、使用方式

面试被问「为什么用 X 不用 Y」时，**不要现场编理由**——本篇每个结论都有实验产物背书（`reports/metrics_*.json` / `scripts/exp_*.py`）。回答结构：结论 → 对照组数字 → 决策准则 → 产物路径。

## 一、聚类：为什么是 K-Means

### 1.1 三模型对比（`models/cluster_compare.py`）

| 模型 | 轮廓系数 | 业务护栏 | 结论 |
|---|---:|---|---|
| **K-Means（K=4）** | **0.4165** | 最小群占比 ≥2% ✅ | 入选 |
| GMM | 0.2536 | 碎群 0.7%（<2% 护栏线）❌ | 淘汰 |
| DBSCAN | 0.0422 | 噪声 5.2%；不可批量打分 ❌ | 淘汰 |

### 1.2 决策准则（预设、非事后）

1. 内部指标：轮廓系数越高越好、inertia 越低越好；
2. 业务护栏：最小群占比 ≥2%，簇数可解释（能映射业务语义）；
3. 长尾鲁棒性：DBSCAN 对极端值更稳，但本项目会员分布无强离群结构；
4. 与先验人群 ARI：有真值时看业务有效性；
5. 可批量打分：新会员稳定分配（K-Means/GMM 可，DBSCAN 需重训）。

结论由规则化准则给出（写在返回的 `recommendation` 字段），**不靠人工挑好看的结果**。

### 1.3 特征空间与神谕上界

- 多候选特征空间按「与先验人群的 ARI」择优，轮廓系数做护栏；全部评估落盘 `metrics_cluster.json`。
- 神谕上界：用生成器埋的 8 类真实人群算轮廓系数 → 回答「0.35 可达不可达」。实测埋点人群在统计特征上部分重叠（ARI≈0.13 量级），**0.4165 已接近该特征空间的天花板**。

## 二、流失模型：为什么是 RandomForest 主口径 + LightGBM 未达标也写入报告

### 2.1 对照组（同一三向时间切分）

| 模型 | 测试集 AUC | 相对 LR 基线增益 | 判定 |
|---|---:|---:|---|
| LR（可解释基线） | 0.7995 | — | 基线 |
| **RandomForest** | **0.830** | **+0.0305** | ✅ 达标（验收线 +0.03） |
| LightGBM | 0.8179 | +0.0184 | ❌ 未达标 |

排序与业务指标：KS 0.4936；Top20% 名单捕获 46.77% 真实流失者（lift 2.34，理论上限 2.72 的 86%）；高危名单 5,014 人。

### 2.2 敏感性实验（`scripts/exp_churn_sensitivity.py`，6 组）

- 变量：训练期数 × 是否有独立验证集 × 特征数量；只比较**测试集 AUC 相对 LR 基线的增益**（默认超参，关注相对趋势）。
- 结论：加入独立验证集后 AUC 增益由 +0.031 降至 +0.027——**这不是调参问题，而是时间外推的真实难度**。LightGBM 未达标是当前数据窗口的天花板，如实写入决策报告而非继续调参。

### 2.3 阈值选择

验证集上按业务成本最优：漏判 1 人 = 误触 8 人（与决策报告 S2 同口径）。不用 Youden 指数——阈值是运营决策不是统计指标。

## 三、CLV：为什么主口径换成 BG/NBD

### 3.1 91 天时间外回测（17,937 名重复购买客户）

| 指标 | BG/NBD + Gamma-Gamma | 简化法 |
|---|---:|---:|
| 金额 MAE | **229.27** | 270.81 |
| MAE 降幅 | **−15.3%** | — |
| Spearman | **0.4449** | 0.4109 |
| 偏差（元/人） | **−1.44（近似无偏）** | +74.40（系统性高估） |

### 3.2 换口径的理由

简化法假设「留存期几何分布 + 月均消费恒定」→ 同客群的人得到几乎相同的价值，**只能排序不能定额**。BG/NBD 用个体购买节奏（frequency/recency/T）区分「低频常客」与「正在流失」，Gamma-Gamma 单独估客单价——定额能力支撑 CLV 分层进画像与决策测算。

### 3.3 保留简化法的理由

每个输入来自已有产物、可逐行追溯；lifetimes 缺失时是显式降级路径（`clv_method=simple_fallback` 留痕）。

## 四、共同纪律

1. **先定验收线再训练**：轮廓 ≥0.35、AUC 增益 ≥+0.03 都是事先写死的。
2. **对照组必须有**：每个主模型旁都有一个更简单的基线（LR / 简化法 / GMM / DBSCAN）。
3. **未达标也报告**：LightGBM +0.0184 未达标照样写进报告，并附 6 组实验说明为什么。
4. **只声明验证过的范围**：CLV 回测「只在 synthetic 数据上验证过」，参数随真实数据重估。
