# 数据字典

## 原始层（data/raw，不入 git）

| 表 | 字段 | 类型 | 含义 |
|---|---|---|---|
| members | member_id / reg_date / gender / age_band / city_tier / store_id / _persona | int64 / datetime / str | 会员表；_persona 为合成数据先验人群，仅用于聚类对照，不做特征 |
| stores | store_id / city / city_tier / area_m2 / open_date | — | 15 家门店 |
| products | sku / category / sub_category / brand / base_price | — | 5000 SKU，品类(60)→子类→品牌三级；含 2% 品类别名脏数据 |
| transactions | txn_id / member_id / store_id / txn_ts / amount / discount | — | 交易流水；含脏数据：重复 0.5% / member_id=-1 缺失 3% / 负金额退货 1% / 时间戳冲突 0.5% |
| transaction_items | txn_id / sku / qty / unit_price | — | 交易明细 |

## 中间层（data/interim，清洗后）

transactions 新增：`is_return`（负金额退货标记）、`net_amount`（净额）、`member_type`（会员/非会员）、`is_logic_error`（时间戳异常标记）。
products：category 已按别名映射表归一。

## 集市层（data/marts）

| 表 | 关键字段 | 说明 |
|---|---|---|
| mart_rfm | member_id, recency_days, frequency, monetary, r/f/m_score, rfm_segment | RFM 指标 + 8 类客群 |
| mart_member_profile | member_id + 25 个画像字段 | 画像宽表（见 指标体系.md §4） |
| mart_churn_score | member_id, churn_prob, risk_level(低/中/高), churn(测试期真实标签), 12 个特征 | 流失打分 |
| mart_basket_rules | antecedents, consequents, support, confidence, lift | 关联规则 361 条 |
| mart_monthly | month, gmv, orders, aov, member_penetration, mom(环比), yoy(同比) | 月度经营汇总（31 个月） |
| mart_quarterly | quarter, gmv, orders, aov, mom(环比), yoy(同比) | 季度经营汇总（2022Q3 不完整） |
